## 1. 产品概述
DS18B20 是 Maxim/Dallas 推出的一款改进型可编程分辨率的 Single-Wire (单总线) 数字温度传感器。它具有微型化、硬件开销低、抗干扰能力强、精度高的特点。
在 ESP32 项目中，常用于消防机器人的环境监测任务。

### 主要特性
- **唯一序列号**：每个器件均有独特的 64 位光刻 ROM 序列号，支持多点组网。
- **电压范围**：3.0V 至 5.5V（建议 3.3V 供电）。
- **测温范围**：-55℃ 至 +125℃；在 -10℃ 至 +85℃ 范围内精度为 ±0.5℃。
- **分辨率**：用户可选择 9、10、11 或 12 位分辨率（默认 12 位）。
- **寄生电源**：支持通过数据线供电（需强上拉）。
- **转换时间**：最大 750ms（12位分辨率）。

## 2. 引脚定义

| 引脚 | 符号 | 描述 | 连接建议 (ESP32-S3) |
| :--- | :--- | :--- | :--- |
| 1 | GND | 地 | 连接到模块 GND |
| 2 | DQ | 数据输入/输出 (开漏) | 连接到任意 GPIO (如 GPIO9)，必须接 4.7kΩ 上拉电阻 |
| 3 | VDD | 电源正极 | 接 3.3V 或 5V (若使用寄生电源模式，此脚接地) |

### ⚠️ 硬件注意
- **上拉电阻**：由于 DQ 线是开漏输出，ESP32 内部上拉较弱（约 50kΩ），可能导致波形畸变。**务必在 DQ 和 VCC 之间外接一个 4.7kΩ 左右的下拉电阻。**
- **长距离传输**：如果线缆较长（>2米），建议在 VDD-GND 间并联一个 1uF 的电容以稳定寄生电源电压。

## 3. 单总线 (1-Wire) 通信协议

所有通信均由**主机 (MCU)** 发起。时序要求微秒级精度。

### 3.1 信号类型
1.  **复位脉冲 (Reset Pulse)**：从机存在指示。
    - 主机拉低总线 > 480μs → 释放总线。
    - 从机检测到上升沿后，等待 15~60μs，随后拉低总线 60~240μs 作为“存在脉冲”。
2.  **写时隙 (Write Time Slot)**：主机向从机写入 0 或 1。
    - **写 0**：主机拉低总线 (1μs ~ 60μs)。
    - **写 1**：主机拉低总线 (< 1μs)，然后在 15μs 内释放总线。
    - **注意**：所有写时隙之间必须间隔至少 1μs。
3.  **读时隙 (Read Time Slot)**：主机读取从机数据。
    - 主机拉低总线 (≥ 1μs) → 释放总线。
    - 主机在 15μs 内读取总线电平。

## 4. 命令集详解

### 4.1 ROM 指令 (用于寻址)
当总线上有多个器件时，必须先进行 ROM 操作。若仅有一个器件，可直接使用 **SKIP ROM**。

| 指令 | 代码 | 功能描述 |
| :--- | :--- | :--- |
| READ ROM | `33h` | 读取 64 位 ROM 码 (仅限单器件且无冲突) |
| MATCH ROM | `55h` | 匹配指定 64 位 ROM 码 (后续跟 8 字节 ID) |
| SKIP ROM | `CCh` | **忽略 ROM 匹配**，直接访问目标器件 (**推荐**) |
| SEARCH ROM | `F0h` | 识别总线上所有器件及其 ID |

### 4.2 存储盒/执行指令
| 指令 | 代码 | 功能描述 |
| :--- | :--- | :--- |
| **WRITE SCRATCHPAD** | `4Eh` | 写暂存器 (TH, TL, 配置寄存器) |
| **READ SCRATCHPAD** | `BEh` | 读取 9 字节暂存器 (第 0,1 字节为温度数据) |
| **CONVERT T** | `44h` | **启动温度转换** (关键！转换期间 DQ 保持高电平) |

## 5. 数据结构 (Scratchpad)

读取到的 9 字节暂存器结构如下：

| 字节 | 名称 | 说明 |
| :--- | :--- | :--- |
| 0 | TEMP_LSB | 温度值低位 (LSB) |
| 1 | TEMP_MSB | 温度值高位 (MSB) |
| 2 | TH_REG | 用户定义高温报警阈值 (EEPROM 备份) |
| 3 | TL_REG | 用户定义低温报警阈值 (EEPROM 备份) |
| 4 | CONFIG | 分辨率配置寄存器 (bit7=0, bit5~1=1) |
| 5-7 | RESERVED | 保留 (通常为 FFh) |
| 8 | CRC8 | 前 8 个字节的循环冗余校验值 |

### 温度计算公式
$$ Temperature (^\circ C) = \frac{TEMP\_MSB \times 256 + TEMP\_LSB}{16} $$
*(注：这是一个 16 位补码数，除以 16 即右移 4 位)*

## 6. ESP32-S3 驱动开发指南

在 ESP-IDF 中实现 1-Wire 协议需要注意以下几点：

### 6.1 关键时序控制
由于 1-Wire 依赖精确的微秒级延时，**在执行位操作时必须屏蔽中断**，防止 FreeRTOS 任务切换导致时序失败。

```c
// 伪代码示例
void ds18b20_write_bit(bool bit) {
    portDISABLE_INTERRUPTS(); // 关中断
    gpio_set_direction(pin, GPIO_MODE_OUTPUT);
    
    if (bit == false) {
        gpio_set_level(pin, 0);       // 拉低
        ets_delay_us(60);             // 维持 60us+
    } else {
        gpio_set_level(pin, 0);       // 先拉低
        ets_delay_us(2);              // 保持短瞬间
    }
    
    gpio_set_level(pin, 1);           // 释放
    gpio_set_direction(pin, GPIO_MODE_INPUT); // 切换为输入
    ets_delay_us(10);                 // 采样点
    
    if (bit == true) {
        // Wait until bus released (if writing 1)
        // Wait loop... 
    }
    
    ets_delay_us(55);     // 确保时隙总时长 >= 60us
    portENABLE_INTERRUPTS();
}
```

### 6.2 常用操作流程 (单次读取)

1.  **初始化**：发送 Reset -> 检测 Presence 脉冲。
2.  **跳过寻址**：发送 `SKIP ROM` (`0xCC`)。
3.  **启动转换**：发送 `CONVERT T` (`0x44`)。
    - *注意*：此后 MCU 需等待至少 750ms (或查询总线状态) 让传感器完成 A/D 转换。
4.  **开始读取**：再次发送 Reset -> Presence。
5.  **再次跳寻**：发送 `SKIP ROM` (`0xCC`)。
6.  **读取暂存器**：发送 `READ SCRATCHPAD` (`0xBE`)。
7.  **循环接收**：连续读取 9 个字节 (可通过 `for` 循环配合上面的 `write_byte`/`read_byte` 逻辑实现)。
8.  **计算结果**：提取 Byte 0 和 Byte 1，代入公式计算。

### 6.3 常见问题排查
- **读数始终为 85℃**：表示尚未进行首次温度转换，或者 EEPROM 未初始化。请检查是否漏发了 `0x44` 指令。
- **读数乱码/CRC 校验失败**：通常由时序不正确或外部上拉电阻阻值过大引起。尝试将上拉电阻减小至 4.7kΩ 或 10kΩ。
- **ESP32 重启**：DS18B20 的瞬时电流较大，建议使用独立的 LDO 供电或在 PCB 设计时考虑去耦。
